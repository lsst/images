`verify-rewrite` gained a `--converted-only` option that queries for the new-format datasets instead of the legacy ones, so it can verify a repository that is only partly converted; without it, a partly converted repository still fails the old-vs-new count check.
CellCoadd comparison failures now report which component (PSF, aperture corrections, provenance), which aperture-correction field, and which cell failed, and field-value mismatches at few points report both operands' values.
`verify-rewrite` gained a `--apcorr-skip-uncovered` option that skips aperture-correction spot-check points where the legacy field does not evaluate, for repositories whose cell centers fall outside every input's coverage; the checker no longer surfaces the legacy evaluator's NaN-cast `RuntimeWarning`.
CellCoadd geometry checks now require only the patch's inner bbox to fit the tract bbox, since the outer sampling ring legitimately spills past tract-edge tracts, and `overlaps_center` mismatches now report each offending input's distance from the cell center to the input's projected edge, distinguishing boundary grazing from geometry errors.
