`VisitImage.from_legacy`, `VisitImage.read_legacy`,
`DifferenceImage.from_legacy` and `DifferenceImage.read_legacy` now require
an `exposure_record` keyword argument.

In the equivalent butler conversions, `exposure_record` is a new _required_
parameter.

Using butler metadata instead of trying to re-translate a FITS header is a lot
safer, because in almost all cases afw will have stripped and/or rewritten
the FITS header with conventions the raw translators do not expect.
