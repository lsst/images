Added `DifferenceImageTemplateInput` and an `inputs` field to `DifferenceImageTemplateInfo`, recording information about each image coadded into a template: its visit, detector, mid-exposure time, coadd weight, and the part of the science image its warp covers.
The `difference_image` schema is now version 1.3.0; files written with earlier versions read with empty `inputs`.
Added `Region.dilated_by`, which pads a region by a distance on all sides as `Box.dilated_by` does for a box, and `Region.convex_hull`.
